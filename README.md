# 🗂️ Life Dashboard

A clean, minimal personal dashboard you can open as a browser homepage.  
Built with pure **HTML · CSS · Vanilla JavaScript** — no frameworks, no backend.

---

## ✨ Features

| Feature         | Details                                                              |
| --------------- | -------------------------------------------------------------------- |
| 🕐 Clock & Date | Live clock with day/date display                                     |
| 👋 Greeting     | Changes based on time of day (morning / afternoon / evening / night) |
| 📝 To-Do List   | Add, edit, mark done, delete tasks — persisted in LocalStorage       |
| ⏱ Focus Timer   | 25-minute Pomodoro timer with animated ring, start/stop/reset        |
| 🔗 Quick Links  | Save favourite sites; opens in new tab; persisted in LocalStorage    |

## 🚀 How to Use

1. Clone or download the repo.
2. Open `index.html` in any modern browser — that's it.
3. No build step, no dependencies.

**Set as browser homepage:**  
Go to your browser settings → set homepage to the local file path or the GitHub Pages URL.

## 💾 Data Storage

All data (tasks and links) is stored in your browser's **LocalStorage**.  
No data is sent to any server.

- HTML5
